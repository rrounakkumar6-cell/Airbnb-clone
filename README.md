# Airbnb Clone

A full-stack rental marketplace inspired by Airbnb. Users can sign up, list their properties with photos, browse places and make bookings.

## Features

- User registration and login with secure session handling
- Create, edit and manage property listings
- Image uploads for listings
- Booking workflow for guests
- Responsive UI for mobile and desktop

## Tech Stack

- **Frontend:** React.js, Tailwind CSS
- **Backend:** Node.js
- **Database:** MongoDB

## Project Structure

```
api/      Backend server (Node.js)
client/   Frontend app (React + Tailwind CSS)
```

## Getting Started

1. Clone the repo
   ```bash
   git clone https://github.com/rrounakkumar6-cell/Airbnb-clone.git
   cd Airbnb-clone
   ```
2. Start the backend
   ```bash
   cd api
   npm install
   npm start
   ```
   Add a `.env` file in `api/` with your MongoDB connection string and auth secret.
3. Start the frontend (in a new terminal)
   ```bash
   cd client
   npm install
   npm run dev
   ```
